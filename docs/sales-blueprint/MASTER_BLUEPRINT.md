## 2. SOP SALES LENGKAP

### SOP-01: PROSPECTING (Cari Lead Baru)

**Tujuan:** Mendapatkan minimal 10 lead baru per minggu per sales

**Sumber Lead:**
1. **Online:** Facebook Marketplace, Instagram, TikTok, Google Business
2. **Offline:** Survey area perumahan, ruko, cluster baru
3. **Referral:** Customer lama, arsitek, kontraktor
4. **Inbound:** WA masuk, telepon masuk, DM Instagram

**Langkah:**
```
1. Posting konten minimal 1x/hari (foto project, tips, before-after)
2. Monitor DM/WA masuk → respon < 5 menit
3. Survey area potensial 2x/minggu (cluster baru, ruko baru)
4. Minta referral ke customer setelah project selesai
5. Input semua lead ke sistem Canopi (nama, lokasi, kontak, sumber)
```

**Standar:**
- Setiap lead WAJIB diinput ke sistem dalam 1 jam
- Setiap lead WAJIB ada foto/video bukti (screenshot chat, foto lokasi)

---

### SOP-02: KUALIFIKASI (Filter Lead Layak)

**Tujuan:** Fokus ke lead yang benar-benar berpotensi closing

**Kriteria Lead Layak (BANT):**
| Kriteria | Pertanyaan |
|----------|------------|
| **B**udget | "Bapak/Ibu ada estimasi budget untuk kanopi?" |
| **A**uthority | "Keputusan pasang kanopi siapa yang menentukan?" |
| **N**eed | "Kebutuhan kanopi untuk apa? (garasi, teras, dll)" |
| **T**imeline | "Kapan rencana mau pasang?" |

**Skoring Lead:**
```
⭐⭐⭐⭐⭐ HOT: Budget jelas + Butuh sekarang + Keputusan sendiri
⭐⭐⭐⭐  WARM: Ada budget + Butuh 1-3 bulan
⭐⭐⭐   COOL: Belum jelas budget + Butuh 3-6 bulan
⭐⭐    COLD: Belum butuh / budget minim
⭐     DEAD: Tidak responsif 2 minggu / tidak layak
```

**Aturan:**
- Lead ⭐⭐⭐⭐⭐ → follow-up intensif (aturan 135)
- Lead ⭐⭐⭐⭐ → follow-up rutin
- Lead ⭐⭐⭐ → nurture (kirim info berkala)
- Lead ⭐⭐ / ⭐ → arsipkan, cek ulang 3 bulan

---

### SOP-03: FOLLOW-UP (Aturan 135)

**Tujuan:** Tidak ada lead yang terlupakan

**Aturan 135:**
- **1** prospek dihubungi setiap **3** hari
- Via **5** cara berbeda: Chat → Voice Note → Telepon → Video → Ketemu

**Jadwal 12 Hari:**

| Hari | Channel | Isi Pesan |
|------|---------|-----------|
| 1 | Chat WA | Tanya kebutuhan + kasih info singkat |
| 2 | Voice Note | Info slot survei / tips bermanfaat |
| 3 | Telepon | Follow-up chat + jadwalkan survei |
| 4 | Video | Kirim hasil project / before-after |
| 5 | Ketemu | Survei lokasi + ukur + estimasi |
| 6 | Chat | Kirim RAB / penawaran |
| 7 | Telepon | Tanya feedback RAB |
| 8 | Video | Testimoni customer lain |
| 9 | Ketemu | Presentasi final + nego |
| 10 | Chat | Follow-up terakhir + urgency |
| 11 | Voice Note | Reminder + penawaran khusus |
| 12 | Telepon | Last call / closing / reschedule |

**Aturan Penting:**
- Setiap follow-up WAJIB kasih **value baru** (info, tips, contoh)
- JANGAN kirim pesan yang sama berulang
- Jika prospek bilang "nanti" → tanyakan kapan tepatnya, catat di sistem
- Jika prospek tidak responsif 3x → turunkan prioritas, cek ulang 2 minggu

### SOP-04: SURVEI (Kunjungan Lokasi)

**Tujuan:** Mengukur, memahami kebutuhan, dan membangun kepercayaan

**Persiapan:**
```
□ Konfirmasi jadwal H-1
□ Siapkan alat ukur (meteran laser / meteran biasa)
□ Siapkan contoh material (foto di HP / sampel fisik)
□ Siapkan portofolio project sejenis
□ Catatan kebutuhan prospek dari chat sebelumnya
```

**Saat Survei:**
```
1. Tepat waktu (maksimal telat 15 menit, kabari jika telat)
2. Observasi dulu sebelum bicara (lihat kondisi rumah, atap, area)
3. Tanya: "Bapak/Ibu concern apa soal kanopi?"
4. Ukur dengan teliti (foto semua sudut)
5. Kasih estimasi kasar (jangan harga final)
6. Jelaskan proses: survei → RAB → deal → produksi → pasang
7. Minta kontak WA yang aktif
```

**Setelah Survei:**
```
1. Input data ke sistem (ukuran, foto, catatan)
2. Buat RAB dalam 1x24 jam
3. Kirim RAB via WA + follow-up
```

---

### SOP-05: PENAWARAN (RAB & Nego)

**Tujuan:** Memberikan penawaran yang jelas, transparan, dan profesional

**Komponen RAB:**
```
1. Spesifikasi material (rangka, atap, finishing)
2. Ukuran detail (panjang x lebar)
3. Harga per item
4. Total harga
5. Syarat pembayaran (DP 50% → pelunasan sebelum pasang)
6. Estimasi waktu pengerjaan
7. Garansi
```

**Teknik Nego:**
```
❌ JANGAN: Langsung kasih diskon
✅ LAKUKAN: Tanya dulu "Budget bapak berapa?"

❌ JANGAN: "Harganya sudah paling murah"
✅ LAKUKAN: "Ini harga terbaik untuk kualitas material X"

❌ JANGAN: Nego tanpa alasan
✅ LAKUKAN: Kasih opsi (material lebih murah / ukuran disesuaikan)
```

**Aturan Diskon:**
- Diskon 0-5% → Sales bisa langsung kasih
- Diskon 5-10% → Minta approval Bos Elvan
- Diskon >10% → WAJIB approval Bos Elvan

---

### SOP-06: CLOSING (Deal & Konfirmasi)

**Tujuan:** Mengubah prospek menjadi customer

**Tanda Prospek Siap Closing:**
```
✓ Tanya detail teknis (material, warna, ukuran)
✓ Tanya kapan bisa mulai
✓ Tanya soal pembayaran
✓ Tanya soal garansi
✓ Setuju dengan harga (atau nego tipis)
```

**Proses Closing:**
```
1. Konfirmasi spesifikasi final (ukuran, material, warna)
2. Kirim invoice / kwitansi DP
3. Terima DP → input ke sistem
4. Jadwalkan produksi
5. Kirim info timeline ke customer
6. Minta referral: "Ada tetangga/kerabat yang butuh kanopi?"
```

**Setelah Closing:**
```
1. Input ke sistem (status: DEAL)
2. Kirim ke tim produksi
3. Follow-up saat produksi: "Proses sudah XX%, estimasi selesai [tanggal]"
4. Follow-up setelah pasang: "Gimana hasilnya? Ada yang perlu diperbaiki?"
5. Minta review/testimoni
6. Minta referral
```

---

### SOP-07: AFTER-SALES (Komplain & Referral)

**Tujuan:** Customer puas → repeat order + referral

**Menangani Komplain:**
```
1. Dengarkan sampai selesai (jangan potong)
2. Minta maaf (meskipun bukan salah kita)
3. Catat detail komplain
4. Eskalasi ke tim teknis dalam 1 jam
5. Follow-up sampai selesai
6. Konfirmasi ke customer: "Sudah selesai, ada lagi yang bisa dibantu?"
```

**Minta Referral:**
```
Timing terbaik:
- Setelah pasang selesai + customer puas
- Setelah customer kasih review positif
- 1 bulan setelah pasang (follow-up berkala)

Script: "Pak/Ibu, kalau ada tetangga, kerabat, atau teman yang 
butuh kanopi, boleh saya bantu. Kami kasih harga spesial 
untuk referral dari customer lama."
```

## 4. SISTEM FOLLOW-UP 135

### Cara Kerja
```
1. Lead baru masuk → input ke sistem
2. Kualifikasi (BANT) → skor lead
3. Lead ⭐⭐⭐⭐⭐ → mulai siklus 135
4. Setiap 3 hari → ganti channel (Chat→VN→Telp→Video→Ketemu)
5. Setiap channel → kasih value baru
6. Monitor respons → update status
7. Closing → after-sales + referral
```

### Tracking di Sistem Canopi
- Setiap lead punya **timeline** otomatis
- Setiap follow-up tercatat (tanggal, channel, isi, respons)
- **Alert otomatis** jika lead tidak di-follow-up > 3 hari
- **Dashboard** untuk Bos Elvan: lead aktif, pipeline, closing rate

## 6. COMPETITIVE ADVANTAGE

### Keunggulan yang WAJIB dibangun:

**1. Respons Cepat (< 5 Menit)**
```
Kompetitor: Balas chat 1-24 jam
Kita: Balas < 5 menit di jam kerja
Cara: Sistem alert + SPV AI pantau
```

**2. Follow-Up Konsisten**
```
Kompetitor: Follow-up 1-2x lalu hilang
Kita: Sistem 135, tidak ada lead terlupakan
Cara: SPV AI track & remind otomatis
```

**3. Garansi Jelas & Tertulis**
```
Kompetitor: Garansi lisan / nggak jelas
Kita: Garansi tertulis di invoice (rangka X tahun, atap Y tahun)
Cara: Template invoice include garansi
```

**4. Transparansi Material**
```
Kompetitor: "Pokoknya bagus"
Kita: Jelaskan spesifikasi material (merek, ketebalan, jenis)
Cara: Sales wajib bisa jelaskan material
```

**5. Portofolio Kuat**
```
Kompetitor: Foto seadanya
Kita: Foto profesional + video + testimoni
Cara: Setiap project wajib dokumentasi before-after
```

**6. After-Sales Jelas**
```
Kompetitor: Pasang selesai, bye-bye
Kita: Follow-up 1 bulan setelah pasang + ada hotline komplain
Cara: SOP after-sales + reminder otomatis
```

**7. Free Survey + Estimasi**
```
Kompetitor: Langsung kasih harga tanpa survei
Kita: Survei gratis → estimasi akurat → deal
Cara: Jadwalkan survei secepat mungkin
```
